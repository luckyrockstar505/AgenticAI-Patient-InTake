# Golden Dataset — `eval/labelled_claims.csv`

Story 2.0 (`_bmad-output/planning-artifacts/epics.md`). Human-labelled scenarios for the claims intake agent — **never generated by the agent itself**. This file is a first draft from Claude Code to accelerate Srimaan + Bharath's labelling pass; every row is marked `review_status=DRAFT-NEEDS-REVIEW` until a human confirms or corrects `expected_tools`, `expected_answer`, and `why`. Flip the column to `CONFIRMED` per row as it's reviewed.

## Columns

| Column | Holds |
|---|---|
| `id` | `G##` (build set) or `H##` (holdout set) |
| `set` | `build` (visible during development) or `holdout` (labels withheld from day-to-day dev use — run once at final eval) |
| `review_status` | `DRAFT-NEEDS-REVIEW` until a human signs off, then `CONFIRMED` |
| `category` | Short tag for coverage tracking |
| `persona` | Which `data/seed/README.md` persona (P1–P7), or a new fixture flagged inline |
| `input` | The turn-by-turn scenario as the member's messages, `\|\|`-separated |
| `expected_tools` | Correct MCP tool call sequence, `->`-separated, per `docs/contracts/mcp-tools.md` |
| `expected_answer` | Correct structured outcome (final state, flags, claim fields) |
| `why` | Why this is correct and which FR/NFR it validates |

## Coverage

20 build-set scenarios: happy path, verify-retry, PENDING_CALLBACK trigger + callback collection, multi-turn clarify, human handoff, no-enumeration, name-format tolerance, cancel, terminated-coverage, mid-flow correction, minor dependent, no-repeat-questions, partial case (missing fields), future-date validation, accident flag, other-insurance flag, pharmacy quick path, adult-dependent out-of-scope boundary, session resume.

10 holdout scenarios: the 8 existing red-team cases (adapted from `evals/datasets/scenarios.jsonl` R01–R08) plus 2 new — concurrency (no cross-session bleed) and a dense single-turn robustness check.
