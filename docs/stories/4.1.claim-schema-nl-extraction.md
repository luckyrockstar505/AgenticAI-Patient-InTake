## Story

**As a** member,  
**I want** to describe what happened in my own words,  
**so that** I don't have to know claim terminology.

## Acceptance Criteria

1. Uses `ClaimDraft` from `shared/schemas.py` (architecture §5). If story 2.5 has not merged yet, land the schema first in a small `contract:` PR approved by both devs.
2. `extract_claim(text, draft, session_date) -> ClaimDraft` uses structured output (`purpose=claim_extract`) and merges without overwriting known values with null.
3. Relative dates resolved against session_date; amounts normalized to Decimal; place_of_service synonyms mapped.
4. Validation errors (future date, negative amount) become `missing_fields` entries with reason.
5. Extraction prompt in `agent/prompts/claim_extract.md`, registered in MLflow.
