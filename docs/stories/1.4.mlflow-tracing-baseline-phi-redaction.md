## Story

**As a** developer / reviewer,  
**I want** every agent turn traced in MLflow with PHI masked,  
**so that** we can debug and evaluate runs without leaking sensitive data.

## Acceptance Criteria

1. `observability/tracing.py` `init_tracing()` sets tracking URI + experiment, enables `mlflow.langchain.autolog()` and `mlflow.litellm.autolog()`.
2. `observability/redaction.py` `redact(obj)` masks member IDs, names from a session-known list, DOB/dates of birth, ZIP, phone, email, NPI; returns masked copy.
3. Redaction is applied to span inputs/outputs (span processor / filter) and to the std logging formatter.
4. Trace tags: `session_id`, `phase`, `app_env`, `git_sha`; naming per `docs/tracing.md`.
5. Unit tests prove seeded PHI strings never appear in exported span JSON.
