## Story

**As a** member,  
**I want** to hear the agent's replies,  
**so that** I can complete the flow hands-free.

## Acceptance Criteria

1. Agent replies synthesized with Amazon Polly (neural voice) and streamed back over the WS.
2. Barge-in: user speech stops current playback.
3. Voice-specific prompt variant: shorter sentences, spells masked IDs, reads numbers naturally.
4. Same safety invariants and evals pass in voice mode.
