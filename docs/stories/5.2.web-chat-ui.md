## Story

**As a** demo audience,  
**I want** a clean chat page that shows the conversation, the verified policy card and the case,  
**so that** the demo is easy to follow.

## Acceptance Criteria

1. Single static `api/static/index.html`, served at `/`, no build step, **ES5-only JavaScript** (no arrow functions, template literals, fetch-streams polyfill via XHR/EventSource).
2. Shows chat bubbles, typing indicator, phase badge, lock icon when verified, policy card, claim summary, and case number banner.
3. Works at 375px width; keyboard accessible.
4. "New session" button.
