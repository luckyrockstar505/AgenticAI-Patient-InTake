## Story

**As a** team,  
**I want** a repeatable offline evaluation of the whole agent,  
**so that** we know when a prompt or model change makes things better or worse.

## Acceptance Criteria

1. `evals/runner.py` replays each scenario in `evals/datasets/scenarios.jsonl` through the graph (fake MCP, LLM mock or bedrock via flag).
2. Scorers in `evals/scorers.py` per `docs/qa/eval-plan.md`: safety invariants, outcome match, field accuracy, clarify turns, intent accuracy, LLM-judge tone (bedrock only).
3. Results logged to MLflow as an evaluation run (`mlflow.genai.evaluate` or `mlflow.evaluate`) with per-scenario traces linked.
4. `make eval` (mock) and `make eval-live` (bedrock) targets; exit code non-zero if thresholds fail.
