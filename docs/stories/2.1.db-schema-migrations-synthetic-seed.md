## Story

**As a** developer,  
**I want** the Postgres schema and realistic synthetic members,  
**so that** tools and evals have deterministic data to work against.

## Acceptance Criteria

1. SQLAlchemy 2.x models + Alembic migration for tables in architecture §4.
2. `make seed` loads `data/seed/members.json` + `coverage.json` idempotently.
3. Seed contains the 7 personas in `data/seed/README.md` (P1–P7: active, lockout target, HDHP, spouse dependent, terminated, not-found ID, deductible met).
4. `make migrate` works in compose and in CI service container.
