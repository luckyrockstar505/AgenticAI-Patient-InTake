## Story

**As a** UI developer,  
**I want** HTTP endpoints to drive the agent with streaming,  
**so that** any front end (web, voice) can use it.

## Acceptance Criteria

1. Endpoints per architecture §8 with pydantic request/response models and OpenAPI docs.
2. `POST /sessions/{id}/messages` streams SSE events: `token`, `state` (phase, verified, policy_card?, claim_summary?, case_number?), `done`.
3. `GET /sessions/{id}` never returns policy data unless verified.
4. Graph + MCP client created once at startup (lifespan); tracing initialized.
5. Rate limit: 30 messages/min/session; message length ≤ 2,000 chars.
