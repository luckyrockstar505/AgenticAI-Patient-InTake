## Story

**As a** member,  
**I want** to speak instead of type,  
**so that** filing a claim feels like a phone call.

## Acceptance Criteria

1. `WS /voice/{session_id}` accepts 16kHz PCM chunks from the browser mic.
2. Streams to Amazon Transcribe streaming (`amazon-transcribe` SDK); partial transcripts sent back to UI; final transcript per utterance fed to the same graph as a text message.
3. Custom vocabulary for member-ID letters/digits; member ID spoken digit-by-digit is normalized.
4. End-of-utterance detection via Transcribe stability + 800ms silence.
