## Story

**As a** team,  
**I want** merges to main to deploy automatically,  
**so that** the demo environment always runs the latest reviewed code.

## Acceptance Criteria

1. `.github/workflows/deploy.yml`: on push to main after CI passes → build & push images tagged with git SHA → run alembic migration task → update ECS services → wait for stable → smoke `/healthz`.
2. Uses `aws-actions/configure-aws-credentials` with OIDC; no static keys.
3. Manual `workflow_dispatch` with image tag input for rollback.
4. Deploy summary (SHA, image tags, URL) in the job summary.
