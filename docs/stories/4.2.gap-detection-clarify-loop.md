## Story

**As a** member,  
**I want** to be asked only for what's missing, one question at a time,  
**so that** filing is quick and not repetitive.

## Acceptance Criteria

1. Computes `missing_fields` from REQUIRED + conditional rules (accident_type if accident).
2. Asks exactly one question for the highest-priority missing field (order in intents.md); may rephrase but must target that field.
3. Never re-asks a field already filled unless the user corrected it.
4. After `MAX_CLARIFY_TURNS` (6) with fields still missing → offers human handoff or continue.
5. Ambiguous answers (e.g., two dates) → asks a disambiguation question for that field.
