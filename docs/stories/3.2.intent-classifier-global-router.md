## Story

**As a** member,  
**I want** to be able to cancel, ask for a human or ask a question at any point,  
**so that** the conversation feels natural and I'm never stuck.

## Acceptance Criteria

1. `router` node implements `docs/intents.md`: regex fast-paths, then fast-model classification into `IntentResult`.
2. Per-phase allowed intents enforced; disallowed/low-confidence → phase default.
3. `cancel` and `request_human` route to terminal nodes from any phase.
4. `abuse`/prompt-injection → refusal message, phase unchanged, audit `safety_event`.
5. Classifier prompt stored in `agent/prompts/intent.md` and registered in MLflow Prompt Registry.
