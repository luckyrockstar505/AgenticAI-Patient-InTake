## Story

**As a** claims ops user,  
**I want** verified, validated claims saved as cases with a case number,  
**so that** backend processing gets complete data with an audit trail.

## Acceptance Criteria

1. `create_case` and `get_case` per contract §5–6.
2. Rejects if verification not PASSED; validates required fields & date within coverage period; returns `VALIDATION` with field list.
3. Case number format `CLM-YYYYMMDD-NNNNN` from a Postgres sequence.
4. Idempotent per session_id.
