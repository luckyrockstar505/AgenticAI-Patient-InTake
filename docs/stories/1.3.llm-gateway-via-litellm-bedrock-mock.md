## Story

**As a** agent developer,  
**I want** one `complete()` function that talks to Bedrock through LiteLLM, or a scripted mock,  
**so that** nodes are model-agnostic and tests never need AWS.

## Acceptance Criteria

1. `agent/llm.py` exposes `complete(messages, *, purpose, schema=None, model_tier='default'|'fast') -> LLMResult` (text, parsed, usage, cost, latency_ms).
2. `LLM_MODE=bedrock` routes via `litellm.completion` to `LLM_MODEL_DEFAULT` / `LLM_MODEL_FAST`.
3. `schema` (pydantic model) produces structured output; invalid JSON → one repair retry → `LLMStructuredOutputError`.
4. `LLM_MODE=mock` returns responses from `tests/fakes/llm_scripts/*.yaml` matched by `purpose` + regex on last user message; unmatched → explicit error naming the purpose.
5. Throttling retries (2, exponential backoff), 20s timeout.
6. Manual smoke script `scripts/smoke_bedrock.py` succeeds with a real AWS profile.
