## Story

**As a** agent developer,  
**I want** one `complete()` function that talks to Bedrock through LiteLLM, or a scripted mock,  
**so that** nodes are model-agnostic and tests never need AWS.

## Acceptance Criteria

1. `agent/llm.py` exposes `complete(messages, *, purpose, schema=None, model_tier='default'|'fast') -> LLMResult` (text, parsed, usage, cost, latency_ms).
2. `LLM_MODE=bedrock` routes via `litellm.completion` to `LLM_MODEL_DEFAULT` / `LLM_MODEL_FAST`.
3. `schema` (pydantic model) produces structured output; invalid JSON → one repair retry → `LLMStructuredOutputError`.
4. `LLM_MODE=mock` returns responses from `tests/fakes/llm_scripts/*.yaml` matched by `purpose` + regex on last user message; unmatched → explicit error naming the purpose.
5. Throttling retries (2, exponential backoff), 20s timeout.
6. Manual smoke script `scripts/smoke_bedrock.py` succeeds with a real AWS profile.

### Completion Notes

- `complete()` shares one repair-retry code path (`_call_with_repair`) between bedrock and mock modes via a small `_Caller` closure, so AC3's "one repair retry" behavior is identical and separately testable in both modes rather than only in the real Bedrock path.
- Mock repair retries are driven by the same regex-matching mechanism as the first call: a mock YAML script that wants to exercise the repair path needs a second `matches` rule whose pattern matches the literal repair-prompt text (`"valid JSON matching this schema"`) — see `tests/fakes/llm_scripts/test_schema.yaml`. Documented in code via `REPAIR_PROMPT_MARKER`.
- `response_format=schema` is passed to `litellm.completion` on every bedrock call (including the repair retry) so the first attempt already asks for structured output; the repair retry is a fallback for when the model still doesn't comply, not the primary mechanism.
- Retry/timeout (AC5) delegates to LiteLLM's built-in `num_retries` + `timeout` kwargs rather than hand-rolled backoff, per architecture §6.
- `make lint`, `make typecheck` (via `mypy agent/`), `make test`, `make eval` all green locally.
