## Story

**As a** team,  
**I want** reproducible AWS infrastructure,  
**so that** the demo runs in the cloud the same way every time.

## Acceptance Criteria

1. `infra/terraform` modules: VPC (2 AZ), ECR (api, mcp-tools), ECS cluster + Fargate services (api behind ALB HTTPS; mcp-tools internal via Service Connect), RDS Postgres (db.t4g.micro), Secrets Manager, CloudWatch log groups, S3 + ECS service for MLflow.
2. ECS task role for api allows `bedrock:InvokeModel` / `InvokeModelWithResponseStream` on configured model ARNs only.
3. GitHub OIDC provider + deploy role scoped to this repo's `main` branch.
4. Remote state in S3 with DynamoDB lock; `terraform plan` clean after apply.
5. Estimated monthly cost documented in `infra/README.md`.
