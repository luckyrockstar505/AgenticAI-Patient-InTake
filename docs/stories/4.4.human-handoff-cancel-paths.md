## Story

**As a** member,  
**I want** to stop or reach a person at any time,  
**so that** I'm never trapped by the bot.

## Acceptance Criteria

1. Handoff node: friendly message, creates audit `handoff_requested` with reason (user_request | locked | clarify_cap | error), phase HANDOFF.
2. Cancel node: confirms cancellation, discards unverified snapshot (status `discarded`), phase CANCELLED.
3. Unhandled exceptions in any node → handoff with reason `error` (graph-level error boundary).
4. After terminal phase, any new message gets a closing message and a hint to start a new session.
