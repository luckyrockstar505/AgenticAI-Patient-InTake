## Story

**As a** developer,  
**I want** every PR automatically linted, type-checked, tested and built,  
**so that** broken code never reaches main and reviews focus on logic.

## Acceptance Criteria

1. `.github/workflows/ci.yml` runs on PR and push to main: ruff, mypy, pytest (unit), docker build for both images.
2. Integration tests run in a job with a Postgres service container.
3. `LLM_MODE=mock` enforced in CI; job fails if any test attempts a real Bedrock call.
4. Branch protection documented in CONTRIBUTING: CI required + 1 approval + squash merge.
5. CI completes in < 8 minutes using uv cache.
