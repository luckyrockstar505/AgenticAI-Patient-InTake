## Story

**As a** tools developer,  
**I want** a mock payer that returns 271-like coverage JSON for a member ID,  
**so that** the agent flow is realistic and we can swap in a real clearinghouse later.

## Acceptance Criteria

1. `mcp_tools/payer_mock.py` exposes `PayerClient` protocol with `get_eligibility(member_id) -> dict | None`.
2. Mock reads `data/seed/coverage.json`; configurable latency (`PAYER_MOCK_LATENCY_MS`) and failure rate (`PAYER_MOCK_FAIL_RATE`) for resilience testing.
3. Timeouts/errors surface as a typed `PayerUnavailable` exception.
4. A `RealPayerClient` stub documents the X12 270/271 mapping (not implemented).
