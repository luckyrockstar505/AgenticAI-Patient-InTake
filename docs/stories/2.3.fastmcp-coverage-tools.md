## Story

**As a** agent (tool consumer),  
**I want** `fetch_coverage` and `get_policy_view` MCP tools per contract,  
**so that** the agent can load coverage and later reveal it only after verification.

## Acceptance Criteria

1. `fetch_coverage`, `get_policy_view` and `end_session` implemented exactly per `docs/contracts/mcp-tools.md` §1, §4 and §7.
2. `fetch_coverage` stores snapshot `status='unverified'` and never returns the payload.
3. `get_policy_view` returns `NOT_VERIFIED` unless verification `PASSED`.
4. Unknown member ID returns `found:false` with no timing difference > 50ms vs found (constant-time-ish delay).
5. Audit rows written: `coverage_fetched`, `policy_viewed`.
6. Contract tests validate every response against JSON Schemas in `tests/contracts/`.
