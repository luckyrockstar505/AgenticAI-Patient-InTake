## Story

**As a** member,  
**I want** to give my member ID and name in whatever way is natural,  
**so that** I can start without filling a form.

## Acceptance Criteria

1. Extracts member_id and full_name from one or multiple turns; asks only for what's missing.
2. Member ID validated against `^[A-Z]{3}\d{9}$` (case-insensitive, strips spaces/dashes) before any tool call.
3. On both present: calls `fetch_coverage`, then `start_verification`; stores ids in state; moves to `verify` and asks the first challenge question.
4. `found:false` → same flow wording as found (no enumeration); verification will fail naturally.
5. Registers member_id + full_name with the redactor.
6. Member ID echoed only masked (`ABC•••••6789`).
