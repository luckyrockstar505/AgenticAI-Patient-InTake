## Story

**As a** member,  
**I want** to be asked a couple of simple security questions,  
**so that** only I can see my coverage and file claims.

## Acceptance Criteria

1. Turns `next_question.prompt_hint` into a natural question (LLM, `purpose=verify_phrase`), never including expected values.
2. Sends raw user answer to `check_answer`; LLM does not judge correctness.
3. PENDING → ask next question; FAILED with remaining attempts → gentle retry message; LOCKED → phase LOCKED, handoff message, END.
4. PASSED → `verified=True`, phase → policy.
5. `repeat` intent re-asks the same question without consuming an attempt.
