## Story

**As a** developer,  
**I want** a single command that starts api, mcp-tools, postgres and mlflow locally,  
**so that** both tracks can build and test against the same environment from day one.

## Acceptance Criteria

1. `pyproject.toml` (uv) with pinned deps from architecture §12; Python 3.12.
2. Folder layout matches architecture §2 with `__init__.py` and placeholder modules.
3. `docker-compose.yml` runs `api` (:8000), `mcp-tools` (:8765), `postgres` (:5432), `mlflow` (:5000); `make up` / `make down` work.
4. `api` exposes `GET /healthz` returning `{status: ok}`; `mcp-tools` exposes a `ping` tool.
5. `.env.example` matches architecture §9; `.env` is git-ignored.
6. `Makefile` targets: up, down, lint, fmt, typecheck, test, eval, seed, logs.
7. README quickstart gets a new dev from clone to `/healthz` 200 in < 10 minutes.
