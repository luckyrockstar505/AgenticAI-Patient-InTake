## Story

**As a** agent developer,  
**I want** the full graph wired with stub nodes, persistent state and a fake MCP client,  
**so that** every later node story just fills in a node.

## Acceptance Criteria

1. `agent/state.py` implements `AgentState` + `Phase` exactly as architecture §3.1.
2. `agent/graph.py` `build_graph(mcp, llm, checkpointer)` wires all nodes/edges in §3.2 with stubs returning canned messages.
3. `PostgresSaver` checkpointer, `thread_id=session_id`; conversation resumes across process restarts.
4. `agent/mcp_client.py` typed async client for all contract tools; `tests/fakes/fake_mcp.py` implements the same interface in-memory from seed JSON.
5. `python -m agent.cli` runs an interactive terminal chat (mock or bedrock).
6. Graph renders to Mermaid (`docs/graph.mmd`) via `graph.get_graph().draw_mermaid()`.
