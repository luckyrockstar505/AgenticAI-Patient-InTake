PRD Fixes — Party Mode Decisions Done
All 4 high-priority blockers resolved · .memlog.md updated (10 entries)
▾
ItemDecision
A-1 ✓Verification failure → callback flow. After 3 failures, agent asks for callback number, calls request_callback tool (writes to callbacks queue). State: PENDING_CALLBACK. No case created, no policy shown. Workshop: mock tool writes to Postgres.
A-2 ✓Minor dependents in scope; adult dependents out. Subscriber files on behalf of minor dependents. patient_name required when patient ≠ subscriber. Adult dependent authorization (HIPAA) is out of scope for MVP.
A-3 ✓No hard turn limit — partial case with flag. Clarify loop asks; if still missing, creates case with missing_fields[] and complete: false. Member hears: "Our team may follow up about [field]."
A-4 ✓Required fields confirmed: date_of_service · place_of_service · provider_name · diagnosis_reason · patient_name (when dependent). [ASSUMPTION] tag removed.

State machine — locked

UNVERIFIED → VERIFIED → (case created)
UNVERIFIED → PENDING_CALLBACK  (3 failures → callback queue)
Any state  → HANDOFF           (member-initiated)
Any state  → CANCELLED         (member cancel)
